Hito 1 - Propuesta

Descripción del proyecto: El proyecto analiza la relación entre el volumen 
comercializado y los precios promedio mayoristas de frutas y hortalizas en Chile 
durante 2026, utilizando datos públicos de la Oficina de Estudios y Políticas 
Agrarias (ODEPA).

Pregunta de investigación: ¿Cómo se relaciona el volumen comercializado con el 
precio promedio mayorista de frutas y hortalizas en los mercados mayoristas de 
Chile entre enero y noviembre de 2026?

Fuente de datos:
- Institución: ODEPA
- Fuente: https://datos.odepa.gob.cl/dataset/precios-mayoristas-de-frutas-y-hortalizas/resource/580beca0-e87e-4dd4-9e8a-0bd92773f4a6  
- Archivo: odepa_ene-nov-2026.csv
- Formato:CSV
- Período: Enero a noviembre de 2026

Herramientas y plan de trabajo: Se utilizarán R para la preparación de datos y 
visualización de resultados, y Stata para la estimación econométrica.

Estructura del repositorio

- data/raw/: datos originales
- data/processed/: datos preparados
- scripts/: códigos de R y Stata
- output/figuras/: gráficos
- output/tablas/: tablas y resultados

Estado del proyecto: La base de datos de ODEPA fue descargada e importada en R. 
Se realizó una revisión inicial de su estructura y variables para comenzar la 
preparación de los datos.
